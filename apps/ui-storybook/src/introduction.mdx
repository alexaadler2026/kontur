# Kontur UI

**Kontur** is the design system shared by **SignFlow** (document signing) and
**Belegscan** (receipt recognition). This Storybook documents the Angular component
library `@adlersoft/kontur-ui` (`libs/ui`).

## Principles

- Hierarchy through typography and spacing, not colour — one brand colour, many neutrals.
- Status is never shown by colour alone: text plus a dot shape.
- Numbers, dates and hashes use IBM Plex Mono with tabular figures.
- Borders, not shadows; shadows only on overlays.
- Accessibility: WCAG 2.1 AA / BITV 2.0 in light and dark theme.
- UI languages: German (default), English, Russian.

## Source of truth

Design tokens, component specs, API contracts and screen mockups live in the repository
under `docs/design/`. Components in this library implement those specs 1:1.

## Status

The library is an empty skeleton. Design tokens and the first components follow
in the next tasks; each component gets its stories here.
