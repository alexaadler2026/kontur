# FileDrop

Зона загрузки файла: drag & drop, выбор, ошибка, прогресс.

- Штриховая рамка `border-input`; drag-over и hover — `brand` + `brand-subtle`; ошибка валидации — `error` + текст причины.
- Доступна с клавиатуры (`role=button`, Enter открывает выбор файла).
