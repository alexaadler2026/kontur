# TextField

Текстовое поле с подписью, подсказкой и ошибкой.

- Подпись — стиль `label` (12/16/500, uppercase); подсказка и ошибка — 12/16 под полем.
- Рамка — `border-input` (3.5:1); ошибка: рамка `error`, фон `error-subtle`, сообщение с иконкой и `aria-describedby`.
- Номера и IBAN — класс `k-num` (Plex Mono, табличные цифры).
