# Switch

Переключатель для мгновенно применяемых настроек.

- 36×20px, включён — `brand`; для выбора в формах с кнопкой «Сохранить» используется Checkbox, не Switch.
- Disabled — класс `is-disabled` на `label.k-switch`: подпись `text-disabled`, курсор not-allowed (как у Checkbox и Radio); дорожка — `border-subtle`.
