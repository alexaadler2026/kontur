# SideNav

Боковая навигация приложения с группами и счётчиками.

- Активный пункт — `brand-subtle` + `brand` 500 + `aria-current=page`; счётчики — `k-num`; низ — профиль пользователя.
- Ширина 232px, на мобильном сворачивается в drawer (CDK Overlay).
