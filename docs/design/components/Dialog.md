# Dialog

Модальный диалог подтверждения с focus trap.

- `bg-surface-raised` + `shadow-overlay-md`, скрим `overlay-scrim`; `role=dialog`, `aria-modal`, фокус на первом действии.
- Деструктивное действие — `danger` справа, рядом secondary «Abbrechen»; Esc закрывает.
