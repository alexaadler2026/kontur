# Checkbox

Чекбокс 16px с подписью слева от текста.

- Отмеченное состояние — заливка `brand`, галочка контрастна в обеих темах; indeterminate — минус.
- Ошибка: рамка `error` и текст `error`; disabled — `bg-subtle` + `text-disabled`.
