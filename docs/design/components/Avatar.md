# Avatar

Аватар с инициалами; фотографии не используются.

- `brand-subtle`/`brand`, стек с наложением −6px и счётчиком «+N»; подпись прогресса подписей — рядом текстом «2/3».
- «+N» в стеке — класс `k-avatar--more` (`bg-subtle` / `text-secondary`). Аватар: `role="img"`, `aria-label` — полное имя; стек — один `role="img"` с общей подписью.
