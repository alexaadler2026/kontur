# DropdownMenu

Контекстное меню действий строки или кнопки «Aktionen».

- `bg-surface-raised` + `shadow-overlay-sm`; деструктивный пункт — `error`, отделён разделителем.
- Клавиатура: стрелки, Home/End, Esc; реализация — CDK Menu.
