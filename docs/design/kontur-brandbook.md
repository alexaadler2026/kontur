# Kontur

Общая дизайн-система приложений **SignFlow** (подписание документов) и **Belegscan** (распознавание чеков). Стиль — *sachlich-modern*: деловой немецкий B2B-продукт, которому доверяют документы и деньги. Точность государственных систем (KERN, GOV.UK) плюс аккуратность современного финтеха. Реализация — Angular, standalone-компоненты на Angular CDK, библиотека `libs/ui` в Nx-монорепозитории; CSS-классы `k-*` этого бандла соответствуют компонентам 1:1.

## Принципы

1. **Иерархия — типографикой и отступами, не цветом.** Один фирменный цвет (петроль), много нейтральных серых. Статусные цвета появляются только по смыслу.
2. **Статус никогда не передаётся только цветом.** У каждого бейджа есть текст, а точка-индикатор меняет форму: круг — успех, ромб — предупреждение, квадрат — ошибка, кольцо — информация. Рамки уверенности OCR различаются типом линии: сплошная / штриховая / пунктирная.
3. **Цифры сравниваются.** Суммы, даты, хэши и номера — IBM Plex Mono с табличными цифрами (`.k-num`), в таблицах выровнены вправо.
4. **Границы вместо теней.** Карточки и таблицы отделяются `border-subtle`; тени есть только у всплывающих слоёв (меню, диалог, toast).
5. **Два продукта — одна система.** Отличается только плотность: SignFlow desktop-first (`control-md` 36px, компакт 32px), Belegscan mobile-first (`control-touch` 44px).
6. **Немецкий — первый язык.** Кнопки и колонки выдерживают «Auftragsverarbeitungsvertrag»: без жёсткой ширины, обрезка с подсказкой. Даты `12.11.2026`, суммы `1.234,56 €`, время 24-часовое.

## Доступность (WCAG 2.1 AA / BITV 2.0)

Контраст рассчитан по формуле относительной яркости WCAG для обеих тем. Полная проверка — 45 пар, все проходят; ключевые значения:

| Пара | Hell | Dunkel | Требование |
| --- | --- | --- | --- |
| text-primary / bg-surface | 17.3:1 | 13.5:1 | 4.5:1 |
| text-secondary / bg-surface | 6.0:1 | 6.4:1 | 4.5:1 |
| brand / bg-surface (ссылки) | 7.8:1 | 6.7:1 | 4.5:1 |
| text-on-brand / brand (primary-кнопка) | 7.8:1 | 7.4:1 | 4.5:1 |
| success / success-subtle (бейдж) | 4.6:1 | 6.2:1 | 4.5:1 |
| warning / warning-subtle (бейдж) | 4.6:1 | 6.2:1 | 4.5:1 |
| error / error-subtle (бейдж) | 5.7:1 | 5.5:1 | 4.5:1 |
| info / info-subtle (бейдж) | 5.5:1 | 6.1:1 | 4.5:1 |
| border-input / bg-surface (рамка поля) | 3.5:1 | 3.5:1 | 3:1 |
| focus-ring / bg-page | 7.8:1 | 7.4:1 | 3:1 |

Правила: видимое кольцо фокуса `focus-ring` 2px со смещением 2px на всех интерактивных элементах; у `text-disabled` контраст намеренно низкий (исключение WCAG для disabled); `border-subtle` декоративна и к 3:1 не обязана — рамки контролов используют `border-input`.

**Отступление от брифа.** Бриф задавал одну границу `#DDE1E6`. Она даёт 1.3:1 и не годится там, где рамка — единственный индикатор границы контрола (WCAG 1.4.11). Поэтому границы разделены: `border-subtle` (#DDE1E6) для разделителей и карточек, `border-input` (#808996 / #6A7584) для полей, чекбоксов и переключателей.

## Типографика

IBM Plex Sans (400/500/600) для интерфейса, IBM Plex Mono (400/500) для чисел и кода. Файлы woff2 (latin, покрывает умлауты и ß) лежат в `fonts/` — open-source лицензия OFL; для кириллицы в продакшене добавляется сабсет cyrillic. Шкала: 12/16, 14/20 (основной), 16/24, 20/28, 24/32, 32/40. Надписи `label` — 12/16/500, верхний регистр, letter-spacing 0.02em.

## Сетка и формы

Шаг 4px: `space-1…space-12` = 4, 8, 12, 16, 24, 32, 48. Радиусы: 4px поля и кнопки, 8px карточки и диалоги, full — бейджи и аватары. Высоты контролов: 36 / 32 (компакт) / 44 (touch).

## Для агентов-потребителей

Макеты SignFlow и Belegscan строятся **только** из этих токенов и классов. Правила: никаких захардкоженных цветов — только `var(--token)`; состояния показываются классами `.is-hover/.is-focus/.is-active/.is-disabled/.is-invalid/.is-loading/.is-selected`; тёмная тема — `data-theme="dark"` на корне. Иконки — Lucide (открытая лицензия), stroke 2, 16–24px, в основных действиях всегда с подписью.
