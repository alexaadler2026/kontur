# План UI-2: KonturToast

Одобрен 2026-11-23. Решения — в `docs/design/components/Toast.md` (коммиты `30ff9ea`,
`0048097`).

## Как устроено

- `provideKonturToast()` при старте приложения добавляет в `<body>` один
  `<k-toast-region>`:
  - две визуально скрытые live-области, `role="status"` и `role="alert"`, пустые с
    самого начала;
  - видимую стопку тостов без ролей, по времени: внизу справа, а при ширине меньше
    960 px — сверху.
- Сервис `KonturToast`:
  - `show(message, options)` кладёт тост в очередь; видны первые 3, остальные ждут,
    пока закроется один из видимых;
  - текст для скринридера (заголовок + сообщение + «Aktion: …») уходит в область по
    тону: info/success → status, warning/error → alert;
  - перед каждым сообщением область очищается, поэтому повтор того же текста
    озвучивается снова.
- Таймер (5000 мс или `durationMs`) только у info/success без действия. Он идёт с момента
  появления тоста на экране и встаёт на паузу, пока на тосте курсор или фокус.
- У каждого тоста крестик (`KonturIntl.closeLabel`). Кнопка действия — `k-button`
  ghost sm: сначала выполняет действие, потом закрывает тост.
- Фокус: тост его сам не берёт. Если фокус был внутри тоста и тост закрылся, фокус
  возвращается туда, где был до входа в стопку. Если того элемента уже нет на странице,
  фокус переходит на `h1`, как у Alert.
- `KonturIntl.actionLabel`: de «Aktion», en «Action», ru «Действие».
- Если `show()` вызван без `provideKonturToast()`, в консоль пишется ошибка с
  подсказкой. Приложение не падает.

## Тесты (сначала красные)

- Области есть до первого сообщения.
- Текст попадает в нужную область по тону; действие попадает в озвучку; повтор
  озвучивается снова.
- Тон: класс и иконка (как у Alert); заголовок выделен; у видимого тоста нет роли.
- Время: info исчезает ровно через 5000 мс, `durationMs` работает. warning, error и
  тост с действием остаются.
- Пауза при наведении и при фокусе: оставшееся время сохраняется.
- Очередь из 3: четвёртый появляется после закрытия одного, и его таймер начинается
  только тогда.
- Крестик и действие; возврат фокуса.
- Stories: все тона и кнопки показа, тёмная тема; axe; e2e: показать с клавиатуры,
  проверить область и закрыть.
