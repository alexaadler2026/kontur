# План задачи 010: Storybook на GitHub Pages (первый CD)

Одобрен 2026-11-14. Решение — [ADR-0005](../adr/0005-storybook-on-github-pages.md): **build once, deploy the tested artifact**.

## Решения (с ответами владельца)

1. **Deploy-job внутри `ci.yml` с `needs: main`** (ответ: да).
   - Job `main` после e2e/axe загружает `dist/storybook/ui-storybook` как артефакт Pages: только `main`, хранение 14 дней.
   - `deploy-storybook` публикует его через `actions/deploy-pages@v5`.
2. **Concurrency** (ответ: да): отмена идущего прогона — только для PR; на `main` прогоны идут очередью. У deploy своя группа `pages` без отмены.
3. **Права.** `pages: write` и `id-token: write` — только у `deploy-storybook`. Оба Pages-шага стоят за условием «`main` и не `pull_request`», поэтому PR из форков исключены.
4. **Подпуть `/kontur/`** проверен локально до коммита.
5. **Ссылка** — в корневом README и README libs/ui.
6. **Журнал 010** — после первого реального деплоя, с фактическим адресом и ответами `curl`.

## Коммиты

1. `docs(adr): host Storybook on GitHub Pages (ADR-0005)`
2. `ci: deploy Storybook to GitHub Pages after green CI on main`
3. `docs: link the published Storybook`
4. `docs(journal): add entry 010 storybook pages` — этот план и журнал.

## Вне задачи

- Деплой приложений — когда появятся экраны.
- Превью для каждого PR — Pages не умеет; позже можно взять другой хостинг.
- Версии Storybook по релизам пакета.
