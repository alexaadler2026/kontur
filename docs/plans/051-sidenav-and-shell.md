  Übersicht, Dokumente (счётчик 12), Gesendet, Protokoll. Ниже группа **VERWALTUNG** с

  темы в макетах нет.**

## UI-4 · SideNav в libs/ui (без зависимости от роутера)

`libs/ui` не знает о роутере: ссылки и активность задаёт приложение (`routerLink`,
`routerLinkActive` с `ariaCurrentWhenActive="page"`), а компонент только оформляет их по
`[aria-current]`. Так он подходит и Belegscan, и Storybook.

| Часть               | Что это                                                               | Доступность                                 |
| ------------------- | --------------------------------------------------------------------- | ------------------------------------------- |
| `<k-sidenav>`       | `<nav>` с обязательным `aria-label`; слоты: `brand`, пункты, `footer` | ориентир (landmark) «Navigation»            |
| `a[k-sidenav-item]` | директива: класс `k-sidenav-item`, иконка, текст, `k-count`           | `aria-current` от приложения; видимый фокус |
| `<k-sidenav-group>` | подпись группы + список                                               | `role="group"` + `aria-labelledby`          |
| счётчик             | `<span class="k-count k-num">`                                        | читается вместе с названием пункта          |

**Шаги, каждый — коммит с тестами (сначала красный):**

1. **UI-4a.** Компоненты и стили 1:1 по `components.css`. Тесты на роли, `aria-current` и
   клавиатуру (Tab по ссылкам). Stories: обычная, активный пункт, счётчики, группа, тёмная
   тема; axe в обеих темах.
2. **UI-4b.** Мобильная панель (drawer) на нативном `<dialog>` (`showModal()`): без новой
   зависимости. Открыть; закрыть по Escape и кнопкой; фокус внутри панели; **после
   закрытия фокус возвращается на кнопку меню**. Внизу панели — слот для переключателей
   языка и темы.

## 8a · каркас SignFlow

0. **8a-0, один languages.json.** Storybook берёт языки из `apps/signflow/public/i18n/languages.json`
   (с `nativeName`) — свою копию `apps/ui-storybook/src/i18n/languages.json` удалить;
   i18n-check и пример в ADR-0006 привести к одному файлу.
1. **8a-1, раскладка.** `ShellComponent` для маршрутов после входа:
   - SideNav слева, шапка, `<main>`;
   - ссылка «Zum Inhalt springen» (переход к содержимому);
   - после перехода фокус ставится на `h1` страницы.
   - В меню **только пункты с готовыми страницами** (сейчас Übersicht); остальные
     добавляются вместе со своими задачами. Группа «Verwaltung» скрыта до задачи 9.
   - Профиль внизу: аватар с **инициалами из e-mail** (`max.beispiel@…` → «MB»: локальная
     часть, `.`/`_`/`-` как пробелы), e-mail, «Abmelden» (сейчас кнопка выхода на `home`).
     Поле «имя» не добавляется.
   - Шапка: поиск, «Neuer Umlauf» и колокольчик **не показываются** до своих задач.
   - Тексты в de/en/ru.
2. **8a-2, тема.** По умолчанию берётся из `prefers-color-scheme`. Переключатель «System /
   Hell / Dunkel» сохраняет выбор в `localStorage`, тема ставится атрибутом `data-theme` на
   `<html>`. Тёмные токены уже есть. Выбор показывается до первой отрисовки, без вспышки
   светлой темы.
3. **8a-3, переключатели в каркасе.** Язык (`sf-language-switch`) и тема — **в шапке справа**;
   на мобильном — **внизу выезжающего меню**.
4. **8a-4, мобильный режим.** Кнопка-«бургер» в шапке открывает drawer из UI-4b.
5. **e2e.** После входа виден каркас. Навигация с клавиатуры. Пункт активен на своей
   странице. axe в светлой и тёмной теме. Мобильная ширина: drawer открывается и
   закрывается.

## Решения владельца (2026-11-25)

1. **Drawer:** нативный `<dialog>`, без `@angular/cdk`; фокус после закрытия — на кнопку
   меню.
2. **Пункты меню:** только пункты с готовыми страницами.
3. **Переключатели языка и темы:** шапка справа; на мобильном — внизу выезжающего меню.
4. **Поиск, «Neuer Umlauf», колокольчик:** скрыты до своих задач.
5. **Аватар:** инициалы из e-mail; поле «имя» не добавлять.
6. **«Verwaltung»:** скрыта до задачи 9.
7. **Storybook:** один общий `languages.json` для приложения и Storybook, без копии (шаг 8a-0).

Порядок: UI-4a → UI-4b → 8a-0 → 8a-1 → 8a-2 → 8a-3 → 8a-4 → e2e.
